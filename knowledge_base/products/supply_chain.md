# 供应链金融

适用客户：核心企业及其上下游供应商、经销商

产品特点：围绕核心企业，为其上下游提供融资支持

申请条件：存在核心企业及真实供应链交易背景

业务场景：上下游融资、批量获客、供应链协同

营销重点：切入核心企业上下游，实现批量获客

# 应收账款融资

适用客户：有稳定下游回款的企业

产品特点：以应收账款质押或转让方式融资

申请条件：有稳定的下游回款与真实应收账款

业务场景：账期管理、回款盘活、现金流改善

营销重点：盘活应收账款，改善企业现金流

# 票据贴现

适用客户：持有未到期银行承兑汇票的企业

产品特点：对持有未到期的银行承兑汇票进行贴现

申请条件：持有真实贸易背景的未到期票据

业务场景：票据融资、流动性补充

营销重点：快速盘活票据资产，补充流动性
